# OpenViking 系统运维治理插件 (openviking-ops)

专为 **OpenViking (VK) 体外大脑** 打造的系统级运维治理与管控特权插件。面向后台运维智能体、哨兵巡检引擎与系统管理员，提供高特权物理算子与 Hook 神经反射守卫。

---

## 🌟 核心价值与特权架构

1. **三位一体运维治理架构**：
   - **MCP 特权工具层**：直连服务端核心接口，提供数据索引重建、底层文件安全原子重定位、死信队列自愈、记忆纯度审计与服务启停重载；
   - **Hook 物理安全守卫**：包含 `SessionStart` 巡检心跳与 `PreToolUse` 破坏性操作安全审计，防止生产误停机；
   - **专家认知导轨**：内嵌系统运维 SOP 与安全护栏，先查后动、原子提交版本快照。

2. **零信任单轨鉴权与安全审计**：
   - 严格要求管理员 Bearer 凭据，物理封杀本地未授权越权操作；
   - 高危操作自动留下审计系谱日志，确保每一项系统级变更具备完整可追溯性。

---

## 🛠️ 本地源码挂载

若已克隆本仓库，在终端执行以下命令即可自举安装至当前宿主：
```bash
cd integrations/antigravity/openviking-ops
python setup.py --install
```
自举向导将自动继承当前环境的管理员认证凭据，并动态绑定自内聚 `server.py` 服务驱动。
