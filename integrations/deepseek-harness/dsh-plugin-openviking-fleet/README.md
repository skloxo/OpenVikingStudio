# 卫星集群同频运维插件 (`dsh-plugin-openviking-fleet`)

跨物理机节点同频健康体检、代码与配置一键同频同步 (2 项跨机工具 + 1 项 Hook 守卫)

## 接入要素
- 服务端端点: 由用户在客户端面板按需填入 (例如 `https://vk.tide.red` 或本地 `http://127.0.0.1:1933`)
- 专属凭据: 用户 API Key (User Key)
- 技能说明书: 本包已内置 `SKILL.md`，智能体安装后激活第一秒自动注入作战记忆

## 安装方式
```bash
npm install https://vk.tide.red/studio/dsh-plugin-openviking-fleet-1.0.3.tgz
```
