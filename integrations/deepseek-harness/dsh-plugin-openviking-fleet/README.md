# 卫星集群同频运维插件 (`dsh-plugin-openviking-fleet`)

跨物理机节点同频健康体检、代码与配置一键同频同步 (2 项跨机工具 + 1 项 Hook 守卫)

## 接入要素
- 服务端端点: `https://vk.tide.red/mcp`
- 专属凭据: 用户 API Key (User Key)
- 智能体 ID: `fleet-mesh@coordinator`

## 安装方式
```bash
npm install https://vk.tide.red/studio/dsh-plugin-openviking-fleet-1.0.0.tgz
```
