# OpenViking 系统运维治理插件 (`dsh-plugin-openviking-ops`)

后台专属运维治理、死信自愈、知识索引重建与哨兵巡检 (17 项运维特权工具 + 2 项 Hook 守卫)

## 接入要素
- 服务端端点: 由用户在客户端面板按需填入 (例如 `https://vk.tide.red` 或本地 `http://127.0.0.1:1933`)
- 专属凭据: 用户 API Key (User Key)
- 技能说明书: 本包已内置 `SKILL.md`，智能体安装后激活第一秒自动注入作战记忆

## 安装方式
```bash
npm install https://vk.tide.red/studio/dsh-plugin-openviking-ops-1.0.3.tgz
```
