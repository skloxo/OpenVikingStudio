# OpenViking 系统运维治理插件 (`dsh-plugin-openviking-ops`)

后台专属运维治理、死信自愈、知识索引重建与哨兵巡检 (17 项运维特权工具 + 2 项 Hook 守卫)

## 接入要素
- 服务端端点: `https://vk.tide.red/mcp`
- 专属凭据: 用户 API Key (User Key)
- 智能体 ID: `openviking-ops@sentinel`

## 安装方式
```bash
npm install https://vk.tide.red/studio/dsh-plugin-openviking-ops-1.0.0.tgz
```
