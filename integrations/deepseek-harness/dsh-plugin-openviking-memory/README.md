## 🌟 核心价值与架构定位

1. **体外大脑全息记忆中枢**：
   - 跨会话统一持久化存储与双向图谱关联，智能体长线重构与多轮对话记忆永不丢失；
   - 预设 `PreInvocation` 先验自动召回预取，零额外 Token 损耗注入上下文。

2. **代码 AST 符号与工作区态势感知**：
   - 原生支持符号大纲提取、跨文件跳转扩展、正则行匹配与双向语义关联；
   - 支撑智能体渐进式展开寻源，避免一次性吞入过多无关文件导致上下文爆炸。

3. **会话无缝交接 (Handover) 与踩坑经验沉淀**：
   - 内置标准化三阶交接规约，一键输出供新会话秒级启动的接力提示词；
   - 疑难排障闭环后支持将物理根因、反思与代码差异原子沉淀至 Evolution Lessons。

## 🧭 接入要素与配置规范 (SSOT)
- **协议模式**：Cordis 原生微内核 + FastMCP 进程间通信通道
- **服务端端点**：默认直连本地 `http://127.0.0.1:1933`（支持自适应远程 `https://vk.tide.red/mcp`）
- **身份鉴权**：支持环境变量 `OPENVIKING_USER_KEY` 或 DSH 本地凭据库自动探测
- **渲染表现**：遵循纯元数据驱动规范，全权委托宿主原生表单与能力发现引擎呈现。
