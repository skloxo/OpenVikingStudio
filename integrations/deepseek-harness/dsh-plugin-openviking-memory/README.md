# OpenViking 核心长程记忆与代码战地 (`dsh-plugin-openviking-memory`)

体外大脑长程记忆语义检索、代码感知、上下文路由与经验沉淀完全体 (34 项战地工具 + 3 项 Hook 物理守卫)

## 接入要素
- 服务端端点: 由用户在客户端面板按需填入 (例如 `https://vk.tide.red` 或本地 `http://127.0.0.1:1933`)
- 专属凭据: 用户 API Key (User Key)
- 技能说明书: 本包已内置 `SKILL.md`，智能体安装后激活第一秒自动注入作战记忆

## 安装方式
```bash
npm install https://vk.tide.red/studio/dsh-plugin-openviking-memory-2.0.15.tgz
```
