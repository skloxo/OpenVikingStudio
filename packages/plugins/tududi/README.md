# Tududi 全域任务管理与 OKR+GTD 生产力中枢插件 (tududi)

专为 **Google Antigravity IDE / Desktop**、**DeepSeek Harness (DSH)** 与全集群智能体打造的一等公民原生任务管理与生产力中枢插件。将公司年度/季度 OKR 战略目标、业务专案 KR 拆解、日常 GTD 研发任务、周期性工程巡检习惯与周报/月报成果归档完全内聚，彻底替代零散的手工台账。

---

## 🌟 核心价值与架构定位

1. **OKR + GTD 五层战略执行咬合**：
   - 严格确立「领域 (Area: 工作/个人) ➔ 目标 (Goal: O1~O4) ➔ 项目 (Project: 核心 KR 载体) ➔ 职能标签 (Tag: 规划/开发/运维/汇报/缺陷) ➔ 两层任务 (Task/Subtask)」五级结构；
   - 项目标题保持简短清爽，具体量化 KR 验收标准内聚于项目描述，旗下全部已完成任务的达成成果自动汇聚为季度/年度结案证明。

2. **智能体三大自动作业神经反射**：
   - 开局自动领活：新会话提及项目时自动盘点进行中与计划内任务，免除人工翻找文档交代背景的负担；
   - 过程随手记分支与完工双行锚点：中途发现分支问题即时挂单零遗忘；结案前强制写入【达成成果】与【解决挑战】，一键支撑周报、月报与 OKR 导出。

3. **双网自愈网关与五重物理拦截守卫**：
   - 内置公网 HTTPS 端点与局域网直连端点毫秒级自动容灾切换，保障全天候零中断响应；
   - 挂载前置拦截守卫，自动完成任务 id 与实体 uid 异构主键纠偏、空主键删除阻断、优先级/状态枚举校验及违规标签拦截。
