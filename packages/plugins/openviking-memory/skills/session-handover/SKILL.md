# 🔄 会话脱水结晶、经验沉淀与无缝接力技能 (session-handover)

> **核心哲学**：单会话由于步数累积存在必然的物理熵增（Token 膨胀、工具漂移、P90 延迟激增）。  
> **核心公理**：**【会话可终结，知识与状态永不回滚】**。会话交接是智能体生命周期的“细胞分裂与新陈代谢”——旧会话负责脱水总结与智力结晶，新会话负责清爽冲锋与极速破局。

## 一、触发场景 (Trigger Scenarios)

当用户输入以下任何自然语言意图时，**100% 自动下意识挂载执行，严禁等待用户下达机械指令**：
- "总结会话"、"整理当前会话"、"交接本次会话"；
- "开新的会话接续任务"、"会话太长了换个新会话"、"无缝接力"；
- "生成接力提示词"、"提纯本会话"、"handoff"、"handover"；
- 或当前会话已完成重大里程碑、单会话步数达到 300+ 步建议主动提议交接。

## 二、三阶交接闭环流程 (Three-Stage Handover SOP)

智能体必须严格按以下三阶闭环顺序执行，杜绝遗漏与口头空谈：

```
[阶段一: 现场脱水] ──► [阶段二: 体外大脑与技能双写] ──► [阶段三: 结晶 Handover Prompt]
 (Git/文件/阻塞点)     (Lessons/Recipes/技能演进)         (五联装结构供新会话秒级启动)
```

### 阶段一：战地清点与现场脱水 (State Dehydration)

1. **检查物理改动状态**：
   - 自动运行 `git status -s` 和 `git diff --stat`（脱水输出，严禁全量 diff 刷屏）；
   - 梳理本次会话新增、修改、重构的关键文件路径清单。
2. **三态事实矩阵切分**：
   - **已确认物理事实 (Verified Facts)**：已修复的 Bug、已通过的测试、已验证可通的 API、确定的系统参数；
   - **未完结任务 (Pending Tasks)**：尚未完成的工单，按 Tracer Bullet 细粒度拆解排序；
   - **核心阻塞点与未决疑问 (Blockers & Open Issues)**：当前卡住的具体原因、报错堆栈或需要进一步决定的技术选型。

### 阶段二：体外大脑双写与技能演进 (Asset Crystallization & Skill Evolution)

1. **踩坑教训入脑 (Evolution Lessons SSOT)**：
   - 若本次会话踩到了参数极限、驱动隐患、网络抖动、未言明前置条件等非显而易见的坑点，**必须调用 `openviking_record_evolution_lesson` 写入体外大脑**；
   - 格式遵循 `Anti-pattern`（故障机理 + 硬性禁令 + 兜底对策）。
2. **成功范式沉淀 (Recipes Formulation)**：
   - 若验证了一套高可靠、可复用的方案或指令序列，调用 `openviking_write` 沉淀至 `viking://resources/master_memory/recipes/`。
3. **技能库自我演进审查 (Skill Reflection)**：
   - 反思本次会话使用现有技能（如 `cockpit-ui`, `auto-pr`, `keepass-vault` 等）时是否发现规则缺漏或反模式；
   - 如有必要，直接更新对应 `SKILL.md`，实现技能闭环进化。
4. **看板留痕**：
   - 若当前工作区存在 `REFACTORING_PLAN.md`，更新任务卡片状态与验收勾选项。

## 三、质量门禁与反模式 (Anti-patterns)

- 🚫 **严禁流水账堆砌**：禁止贴出“我先做了A，然后用户说了B，接着我报错了C”的冗长对话回放；新会话只需要**脱水后的事实骨架**；
- 🚫 **严禁留白模糊词**：禁止出现“继续完善剩余功能”、“把剩下的修完”等模糊表述，必须明确到具体文件与具体工单；
- 🚫 **严禁经验只留私聊**：踩坑经验必须第一时间调用 OpenViking 工具沉淀，禁止随着会话关闭而湮灭。
