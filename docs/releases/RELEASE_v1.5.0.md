## 🚀 七大核心技术突破与演进细节 (Key Innovations & Breakthroughs)

### 1. 📏 单文件工程重构与 LLM 注意力集中度突破 (Single-File Architecture SSOT)
- **物理痛点**：此前代码库中存在多个历史巨石文件（如 `skills/route.tsx` 达 1,906 行、`tasks/route.tsx` 达 1,255 行、双语字典 `zh-CN.ts` 达 2,286 行），严重超出单次 `view_file` 800 行视野上限，触发 LLM 注意力 Lost in the Middle U 型衰减与行号匹配漂移；
- **治理成果**：严格落实 `AGENTS.md` 黄金甜点区（100~300 行）与物理硬红线（≤ 500 行）：
  - **任务路由**：按领域接缝拆分为 Hook、API、指标卡片、筛选条、表格 5 大模块，入口容器代码从 1,255 行骤降至 **146 行**；
  - **技能路由**：解耦为类型、翻译、数据请求、卡片展示、抽屉等 8 个高内聚模块，入口容器代码从 1,906 行骤降至 **116 行**；
  - **双语字典**：按业务域正交拆解为 9 个独立模块并在 `index.ts` 聚合导出，消除巨石字典；
  - **全系统达标**：全代码库所有新增与重构文件 100% 落在合规安全区间。

---

### 2. 🛰️ 全集群 Agent 统一身份穿透与对等感知网络 (Full Cluster Agent Mesh: `client@node`)
- **物理痛点**：历史调用中缺乏显式身份标记，后端写请求盲目退化为 `default` 租户名；3070 节点 Antigravity IDE 与 WorkBuddy 客户端共用同一 MCP 造成身份串扰；首页看板误将 Mac Studio 离线算力混淆为智能体实体 (`mlx-agent`)；
- **治理成果**：
  - **工业级统一身份规范**：制定并推行 `{client}@{node}` 身份契约（如 `antigravity@2080ti`、`workbuddy@3070`、`openclaw@2080ti`）；
  - **双重环境自动嗅探**：升级核心与卫星 MCP，引入进程执行特征与环境变量指纹双重自动识别，彻底消除多客户端共用脚本身份冲突；
  - **算力与智能体边界厘清**：彻底肃清 `mlx-agent` 幻觉实体，精准收口全集群 7 大真实在籍干活智能体；
  - **首页真实对等看板**：首页 Agent Peer 看板全面基于真实消息累加驱动，透传 `[NODE] Client` 高密徽章。

---

### 3. 📱 XiaomiMiMo (小米客户端) 跨节点 ESM 原生插件大一统与直接记忆流注入
- **物理痛点**：2080Ti 与 3070 双节点配置割裂；MiMo 桌面端反编译查明其对钩子强制调用 `Bun.build`，在 Electron 环境下抛出 `Bun.build is not a function` 致命崩溃；官方 `system.transform` 钩子被后端忽略导致核心记忆注入失效；
- **治理成果**：
  - **纯 Node.js 原生 ESM 插件**：彻底去除对外部 Python/WSL 子进程的依赖，使用原生 `fetch` 与毫秒级 AbortController，预取时延降至 < 10ms；
  - **消息流直接注入 (`messages.transform`)**：将体外大脑核心记忆直接拼接入用户消息流 `lastUserMsg.parts`，彻底保证大模型 100% 收到真实记忆；
  - **全集群实机闭环**：远端 3070 与本地 2080Ti 双端实机测试 4/4 题目 100% 准确命中，4096 引擎稳定拉起。

---

### 4. ⚖️ 双轨任务中心自解释看板与绝对数据真实性治理 (Dual-Track Task Engine)
- **物理痛点**：任务列表充斥裸 UUID 与机器黑话，原子入库无脑渲染 `+4 ~1 -0` 虚假衍生条目，工序进度假分母抢跑导致数据割裂；
- **治理成果**：
  - **双轨自解释看板**：宏观主看板展示有头有脸的业务大任务（中文自解释标题、真实耗时、发起人徽章），底层工序折叠收拢为二级面板；
  - **绝对数据真实性**：彻底拔除前端 `task-pipeline-diagram.tsx` 中硬编码假数据，100% 严格由后端真实入库决策 `decision.action` 驱动；
  - **实事求是推导引擎**：将 1,671 行单文件拆解为 Schema 注册表 + 通用推导引擎 + 精简入口，动作工序与量化工序物理分离；
  - **单行高密度座舱排版**：严格单行 40px 行高，成果物直达抽屉收拢，支持一键复制与外部直达。

---

### 5. 🛡️ 卫星 MCP 并行超时自愈与安全分层防线 (Satellite MCP Hardening)
- **物理痛点**：卫星节点在并发检索时触发 `-32001` 超时崩溃，FastMCP stdio 事件循环死锁，危险特权运维接口在端侧裸露；
- **治理成果**：
  - **30s 预算对齐**：宿主配置超时由 5s 升级标定为 30s (30000ms)，解除时钟错位；
  - **线程池异步卸载**：同步工具通过 `asyncio.to_thread` 卸载至独立线程池执行，解除 stdio 阻塞；
  - **并发信号量保护**：重型检索池注入 `asyncio.Semaphore(2)`，4 工具并发调用 5.94s 平滑通过；
  - **纯 User Key 契约**：卫星模式精简暴露 16 大非特权安全工具，彻底切除 42 个特权运维接口，杜绝安全泄露。

---

### 6. 🧬 抗熵增记忆前门防御与裁决流水总账 (Entropy Gatekeeper)
- **物理痛点**：知识库 Append-Only 无序膨胀引发向量密集区信噪比衰退；
- **治理成果**：
  - **轻量准入判定 (`Admission Check`)**：入库执行向量四态比对（ADD 独立新增 / NOOP 同义合并 / UPDATE 增量演进 / DLQ 异常隔离）；
  - **唯一流水号与持久化**：生成全局唯一流水号 `#dec_xxxx`，落地 30 天滚动持久化与自动修剪；
  - **大盘可审计**：Studio 记忆大盘与详情抽屉支持真实翻页与 5 态分类过滤，中英双语完全对齐。

---

### 7. 🌊 第三代自主进化与零幻觉 5-Wave DAG 战略确立
- **物理痛点**：学术玩具 `500xCompressor` 黑盒不可解密无法工程落地，盲目自进化容易导致模型作弊与近亲繁殖；
- **治理成果**：
  - 吸收 20 篇高信任一手工程成果，经受芒格逆向审问（倒推死因）与红蓝对抗审裁；
  - 确立 **5-Wave DAG 演进拓扑 (v1.5.01 ~ v1.5.24)**：
    - Wave 1: 运行时与脚手架地基 (pi 双层循环、四不变式、DECO 读写护栏、物理验真)
    - Wave 2: 零幻觉混合检索与端侧导航 (FTS5 BM25、zg 端侧分级搜索、弃答门禁)
    - Wave 3: 上下文保真与记忆生命周期 (零思考二分、FSM 状态机、Notes/History 双轨分仓)
    - Wave 4: 契约化自演进与离线梦境 (Skill-as-Code、AHE 契约三元组、Polar 判官)
    - Wave 5: 效能度量与前瞻运营 (SNR/P@5 探针、大盘看板、Wiki 离线脱水)
  - 彻底剔除 `500xCompressor`，正式替换为**阿里 SkillZip**（写入即压缩防膨胀 30%+）与 **Codex 级 Notes-History 双轨分仓**（切除有损全局压缩）。

## 🛠️ 升级与兼容性指南 (Upgrade Guide)

   ```bash
   systemctl --user restart openviking
   ```

   ```python
   openviking_fleet_sync(target_node="all")
   ```
