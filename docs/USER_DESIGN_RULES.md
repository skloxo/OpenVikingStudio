# 用户产品设计与文案偏好黄金法则 (User Design & Wording Golden Rules)

## 📌 核心准则：拒绝技术黑话自嗨，面向真实用户传递直觉价值

在 OpenViking Studio (VK) 所有 UI 界面、交互提示词、文档与后续功能的迭代中，**必须**遵守以下由用户指定的通俗化表达规则：

---

### 🌟 正面标杆案例 (Golden Examples)

| 原抽象技术黑话 ❌ | 🌟 必须采用的通俗直白命名 ✅ | 💡 核心原因与交付效果 |
| :--- | :--- | :--- |
| **`实时 API 直连`** | ⚡ **`本地直连`** | 极其形象地传递“就在这台机器本地，直接高速连通”的直觉 |
| **`API 客户端`** | 🌐 **`网络远程`** | 极其清晰地传递“通过远程接口/跨网络连接”的含义 |
| **`VK 连接方式`** | **`对接通道`** | 大白话，避开重复 API 单词与学术绕口令 |
| **`ACTIVE / SYNCED / IDLE`** | 🟢 **`活跃`** / 🟣 **`空闲`** / ⚪ **`休眠`** | 双字极简，一目了然，完全剔除“已同步”的模糊感 |

---

### 🛠️ 自动化与性能黄金原则

1. **零资源浪费与奥卡姆剃刀**：拒绝过度工程化（如非必要不增加全双工 WebSocket 长连接）。
2. **按需焦点感知 (Focus Awareness)**：离开标签页时 100% 挂起轮询，点回视口时 100ms 瞬间补充补发。
3. **数据真实性铁律 🔴**：绝对禁止伪造或广播假数据，没有拆分 API 处宁可优雅显示 `--`。
